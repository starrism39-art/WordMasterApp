# WordMaster 正式会员 UI 首发版开发规格 · Final

## 1. 定稿范围

正式会员入口固定在“我的”页面，采用简化版方案 B。

首发页面：

| 页面形态     |            |
| -------- | ---------- |
| 我的页面会员入口 | 现有页面新增入口   |
| 会员主页     | 8种状态共用一个页面 |
| 选择保留学生   | 独立页面       |
| 我的订单     | 独立列表页      |
| 订单详情     | 独立详情页      |
| 会员规则     | 独立说明页      |
| 客服与支付问题  | 独立最小可用页    |

视觉方向固定为：

- WordMaster 2.0 雾灰背景
- 深墨蓝文字
- 绿色主要操作
- 克制圆角和低强度阴影
- 状态驱动的教师工具型页面
- 不使用金色VIP、皇冠、大面积营销渐变、复杂动画或过多卡片
- 不显示任何测试、阶段或内部实现文案

## 2. 路由建议

当前“我的”页面为 `pages/students/students`。

| 页面建议路由  |                                           |
| ------- | ----------------------------------------- |
| 会员主页    | `subpages/membership/index`               |
| 保留学生    | `subpages/membership/retain-student`      |
| 我的订单    | `subpages/membership/orders`              |
| 订单详情    | `subpages/membership/order-detail?id=...` |
| 会员规则    | `subpages/membership/rules`               |
| 客服与支付问题 | `subpages/membership/support`             |

订单详情仅通过路由传递订单标识。金额、状态、支付时间和会员期限必须由会员服务重新读取，不得通过 URL 传递。

## 3. “我的”会员入口

入口放在教师资料区域下方、普通功能列表上方，采用单行工具入口，不做营销横幅。

- 图标：绿色浅底的线性盾牌或证件图标
- 主标题：`教师会员`
- 副标题：根据统一展示模型显示
- 右侧：进入箭头
- 即将到期或需要选择保留学生时，可显示克制的橙色提示点
- 点击整行统一进入正式会员主页

| 展示状态副标题 |                 |
| ------- | --------------- |
| 免费版     | 免费版             |
| 个人缓冲期   | 缓冲期剩余 X 天       |
| 教师会员    | 有效期至 YYYY/MM/DD |
| 即将到期    | X 天后到期          |
| 已到期     | 已到期             |
| 长期会员    | 长期有效            |

## 4. 页面减法原则

每个会员状态页只回答三个问题：

1. 用户现在是什么状态
2. 用户现在最需要知道什么
3. 用户现在最需要做什么

不得在每个状态页重复完整的会员权益、数据保障和会员服务说明。

页面结构按当前状态组合以下模块：

- 状态标题
- 必要期限或访问范围
- 一个主操作
- 必要时一个次操作
- 简短的数据保留提示
- 服务入口

## 5. 会员主页状态规格

| 状态显示内容主按钮次按钮状态标签 |                                       |        |        |       |
| ---------------- | ------------------------------------- | ------ | ------ | ----- |
| 免费版              | 免费状态；累计可新增1名学生；399元/12个月；不自动续费；学生数量不限 | 开通会员   | 无      | 免费    |
| 教师会员             | 有效期；剩余天数；续费价格和规则                      | 提前续费   | 无      | 有效    |
| 即将到期             | 剩余天数；到期日期；到期后数据不会删除                   | 立即续费   | 无      | 即将到期  |
| 个人缓冲期            | 剩余X天；现有学生仍可使用；缓冲结束后的免费名额规则            | 开通会员   | 无      | 剩余X天  |
| 已到期·单学生          | 当前仍可访问1名学生；历史数据仍保留                    | 重新开通会员 | 无      | 已到期   |
| 已到期·多学生待选择       | 当前学生数量；免费版需固定保留1名学生                   | 重新开通会员 | 选择保留学生 | 待选择   |
| 已到期·已选择          | 已保留学生；其他学生暂不可访问；开通后恢复全部               | 重新开通会员 | 无      | 已保留1名 |
| 长期会员             | 长期有效；学生数量不限                           | 无      | 无      | 长期有效  |

### 免费版文案

- `当前账户`
- `免费版`
- `累计可新增 1 名学生`
- `399元 / 12个月`
- `不自动续费`
- `开通后学生数量不限`

### 教师会员文案

- `教师会员`
- `有效期至 YYYY年MM月DD日`
- `剩余 X 天`
- `续费后从当前到期日顺延12个月`

有效状态不重复展示大段会员权益或数据保障。

### 即将到期文案

- `教师会员即将到期`
- `剩余 X 天`
- `到期时间 YYYY年MM月DD日`
- `到期后学生和历史数据不会删除`

其他信息弱化，续费按钮保持页面唯一主操作。

### 个人缓冲期文案

- `个人缓冲期`
- `剩余 X 天`
- `当前仍可继续使用现有学生`
- `缓冲结束后，免费版仅可保留1名学生`
- `其他学生及历史数据不会删除`

### 已到期文案

- `会员已到期`
- `免费版可继续访问1名学生`
- `其他学生和历史数据仍会保留`
- `重新开通后可恢复全部访问`

多学生尚未选择时，必须提供“选择保留学生”次操作。

### 长期会员展示边界

会员主页支持长期状态：

- 显示 `长期会员`
- 显示 `长期有效`
- 显示 `学生数量不限`
- 不显示399元购买卡
- 不显示开通或续费按钮
- 可以进入我的订单和客服与支付问题

以下普通用户内容不得出现长期会员或内部权益来源：

- 会员规则页
- 购买说明
- 普通会员介绍
- 免费版、缓冲期、到期状态说明

禁止向用户展示：

- `long-term`
- 长期内部会员
- `gift`
- `historical`
- `admin adjustment`
- 赠送来源、历史补录、管理员调整等内部概念

这些仅属于服务端内部身份或权益来源，不属于普通会员产品说明。

## 6. 会员服务入口

除非当前状态不适用，会员主页底部统一提供：

- 我的订单
- 会员规则
- 客服与支付问题

服务入口使用紧凑列表，不拆成多个大型说明卡片。

长期会员可以进入：

- 我的订单
- 客服与支付问题

普通会员规则页仍只介绍正式公开的399元年度会员规则。

## 7. 我的订单

订单列表至少显示：

- `教师会员 · 12个月`
- 实付金额
- 支付时间
- 自然中文状态
- 对应会员期限

允许展示的订单状态：

- 支付成功
- 正在确认
- 已关闭
- 已退款
- 其他经过业务确认的自然中文状态

不得展示：

- `grant`
- `ledger`
- `paidAt`
- `platform transaction id`
- 内部授权来源
- 原始支付状态码
- 调试状态

点击订单进入订单详情。列表底部提供“客服与支付问题”入口。

## 8. 订单详情

订单详情至少显示：

- 商品：教师会员 · 12个月
- 实付金额
- 支付状态
- 支付时间
- 会员有效期
- 脱敏订单号
- 客服与支付问题入口

订单号示例：

`WM2026••••4821`

订单确认中时显示：

- `正在确认支付结果`
- `支付结果可能存在短暂延迟`
- `刷新状态`

前端支付成功回调不得直接把会员状态显示为已生效。最终状态以会员服务返回结果为准。

普通订单详情不提供常规退款入口。

## 9. 保留学生选择

页面标题：

`选择保留学生`

页面说明：

- `请选择1名保留学生`
- `确认后，免费版将继续开放该学生`
- `其他学生及历史学习数据不会删除`
- `重新开通会员后可恢复全部访问`

学生列表项显示：

- 头像或姓名首字
- 学生姓名
- 年级或当前词书
- 单选状态

底部固定主按钮：

`确认保留`

交互要求：

- 未选择学生时按钮禁用
- 提交中禁止重复点击
- 提交失败时保留当前选择并提供重试
- 是否允许提交后更换保留学生，完全服从既有业务规则
- 页面不得自行提供业务未授权的更换或撤销入口

## 10. 会员规则

普通用户可见的会员规则只保留5项。

### 价格与有效期

399元 / 12个月，不自动续费。

### 学生名额

免费老师生命周期累计只能新增1名学生；会员期间学生数量不限。

### 续费

有效会员提前续费，从当前到期日顺延12个月。

### 缓冲与到期

符合条件的历史老用户，第一次打开会员新版后享受个人5天缓冲。多学生免费用户缓冲结束后需固定1名保留学生。

### 数据保障

会员到期不会删除学生及历史学习数据；后续重新开通会员可恢复访问。

规则页不得出现长期会员、赠送、历史补录、管理员调整或任何内部状态来源。

## 11. 客服与支付问题

页面保留以下问题分类：

- 已付款但会员未生效
- 订单状态未更新
- 会员有效期疑问
- 其他会员问题

### 客服入口规则

当 `supportAvailable = true`：

- 展示业务方配置的真实客服入口
- 按钮文案根据真实渠道确定
- 点击行为使用业务方正式提供的联系方式或平台能力

当 `supportAvailable = false`：

- 页面继续正常展示问题分类和必要说明
- 不展示点击后无效的“联系客服”按钮
- 不虚构微信号、手机号、客服链接或其他联系方式
- 可显示中性提示：`客服方式正在完善，请稍后再试`

正式发布前，真实客服方式属于必须补齐的上线配置项。

## 14. 统一服务端展示模型

正式会员主页、我的入口、订单页和相关页面必须统一消费会员服务提供的展示模型。

至少包含：

- `displayState`
- `statusLabel`
- `expiresAtText`
- `remainingDays`
- `transitionRemainingDays`
- `studentCount`
- `freeStudentLimit`
- `retainedStudentId`
- `retainedStudentName`
- `needsRetentionSelection`
- `canPurchase`
- `canRenew`
- `priceText`
- `durationText`
- `autoRenewText`
- `orders`
- `orderDetail`
- `supportAvailable`

页面只根据展示模型决定：

- 展示哪些模块
- 显示哪个按钮
- 按钮是否可用
- 展示哪些自然中文文案

禁止：

- WXML自行计算会员资格
- 页面 JS 自行判断到期规则
- 页面 JS 自行计算免费学生名额
- 页面根据数据库原始字段推断权益来源
- 页面拼接多个数据库记录形成会员状态
- 页面直接展示服务端内部状态名
- 前端支付回调直接授予或确认会员权益

内部原始状态必须由会员服务统一归一化为 `displayState`，再映射为用户可见中文。

用户界面禁止出现：

- `free`
- `active`
- `expired`
- `transition`
- `long_term`
- `legacy_free_candidate`
- `PAYMENT_PENDING_REVIEW`
- `grant`
- `ledger`
- `Stage5`
- 其他数据库字段名或调试枚举

统一使用自然中文：

| 内部展示状态用户文案 |             |
| ---------- | ----------- |
| 免费状态       | 免费版         |
| 有效状态       | 教师会员 / 有效   |
| 临近到期       | 即将到期        |
| 缓冲状态       | 个人缓冲期       |
| 到期状态       | 会员已到期       |
| 长期状态       | 长期会员 / 长期有效 |
| 支付确认中      | 正在确认支付结果    |

内部权益来源不参与普通用户文案。

## 16. Loading、Empty、Error、Disabled

### Loading

- 使用骨架屏或局部占位
- 保留页面结构
- 不显示免费版等默认状态
- 不在加载完成前开放购买、续费或保留学生提交

### Empty

- 订单页显示：`暂无会员订单`
- 其他页面缺失会员数据时不得自动判断为免费版
- 缺少数据应进入错误或重新加载状态

### Error

- 文案：`会员信息暂时无法获取`
- 操作：`重新加载`
- 错误状态不开放购买、续费或保留学生提交

### Disabled

适用场景：

- 支付处理中
- 状态确认中
- 保留学生未选择
- 请求正在提交
- 页面数据尚未完成校验

按钮文案可使用：

- `正在确认`
- `正在提交`
- `请选择学生`

### 支付确认中

- 显示：`正在确认支付结果`
- 允许用户重新进入后恢复查询
- 不直接显示会员已生效
- 禁止重复发起同一笔支付

### 客服未配置

- 页面可进入
- 问题分类正常显示
- 不展示无效联系客服按钮
- `supportAvailable = false` 时仅显示中性提示

所有到期和访问限制提示必须明确：

`限制访问不等于删除数据。`
